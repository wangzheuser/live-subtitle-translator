## English

- Added 13 editable text-service presets with provider icons and links for API keys and setup. ChatMock now appears last in the service list.
- Fixed Android losing an explicit Custom preset when its settings screen is recreated, and Save or Check using the previous service's fields after a rapid switch.
- Fixed Android saved-session pages opening at the bottom. Accepted exports now finish through refreshes and closing the reader.
- Clarified DeepL and DeepLX connection messages for rate limits and exhausted quotas.

Update through the app or download the package for your platform. Android keeps its existing signing identity. Quit portable Windows builds before replacing the executable. macOS packages remain self-signed and are not Apple-notarized. On Ubuntu/Debian, install `libgles2` if an AppImage reports it is missing.

Android regression checks used an emulator. Physical Windows/Linux/Android devices, all Android document providers, live-service accuracy and latency, complete in-place updates and long-running sessions remain unverified.

## 中文

- 新增 13 项可编辑的文字服务预设，提供服务图标、密钥获取和配置指南入口。ChatMock 调整至服务列表末尾。
- 修复安卓设置页面重建后丢失「自定义」预设选择，以及快速切换服务后保存或检查连接使用旧服务字段的问题。
- 修复安卓已保存会话翻页后停在底部的问题。已接受的导出现在可在刷新或关闭阅读页后继续完成。
- 改善 DeepL、DeepLX 的限流和额度耗尽提示。

可在应用内更新，或下载对应平台的安装包。安卓沿用现有签名身份。Windows 便携版请先退出 Mimi，再替换程序。macOS 安装包仍采用自签名，未经 Apple 公证。Ubuntu/Debian 的 AppImage 若提示缺少 `libgles2`，请先安装它。

安卓回归使用模拟器。实体 Windows／Linux／Android 设备、全部安卓文档提供者、真实服务准确率与延迟、完整覆盖升级和长时间会话仍未验证。
