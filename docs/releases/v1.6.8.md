## English

- Apple translation can recover an initially unready session using language packs already installed. Failed Apple resource checks can be retried from Settings.
- Improved session export reliability when cancelling an operation or changing sessions. Failed history and transcript reads now offer Retry without losing your current page or filters.
- Subtitle previews update after corrections to decimal points, negative signs and other meaningful punctuation. This fix is shared by desktop and Android.
- Original-only mode opens the appropriate settings page. Repeated Pause/Resume actions from different desktop windows no longer reverse an unfinished action.

Update through the app or download the package for your platform. For portable Windows builds, quit Mimi before replacing the executable. macOS packages remain self-signed and are not Apple-notarized. Apple features still require a supported macOS version and installed language packs.

Linux AppImages use host graphics libraries. If startup reports `Couldn't open libGLESv2.so.2`, install `libgles2` on Ubuntu/Debian (`sudo apt install libgles2`).

Full in-place updates, live translation sessions and physical Windows, Linux and Android devices were not revalidated for this release.

## 中文

- Apple 翻译可以利用已安装的语言包，恢复初始未就绪的会话。Apple 资源检查失败后，可在设置中重试。
- 改善取消操作或会话变化时的导出处理。历史记录和全文读取失败后可重试，并保留当前页码与筛选条件。
- 小数点、负号等有实际含义的标点被修正后，字幕预览会更新译文。此修复由桌面和 Android 共用。
- 仅显示原文时进入对应的设置页。从不同桌面窗口重复暂停或继续，不再反转尚未完成的操作。

可在应用内更新，或下载对应平台的安装包。Windows 便携版请先退出 Mimi，再替换程序。macOS 安装包仍采用自签名，未经 Apple 公证。Apple 功能仍需要受支持的 macOS 版本及已安装的语言包。

Linux AppImage 使用系统图形库。如果启动提示 `Couldn't open libGLESv2.so.2`，请在 Ubuntu/Debian 安装 `libgles2`（`sudo apt install libgles2`）。

本次未重新验证完整覆盖升级、真实翻译会话及 Windows、Linux、Android 实体设备。
