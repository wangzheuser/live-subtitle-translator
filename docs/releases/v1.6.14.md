## English

- Added official API key links to built-in speech services and DeepL/Grok text translation on desktop and Android.
- Fixed Android reusing old credentials after changing an Azure resource, Tencent AppID/SecretID or Baidu AppID. Equivalent Azure addresses now keep their saved key.
- Fixed connection-check buttons becoming available before a check finishes, and outdated configuration errors remaining after correction on Android.
- Made update versions, download progress and verification status clearer, and shortened setup and status messages.

Update through the app or download the package for your platform. Quit portable Windows builds before replacing the executable. macOS packages remain self-signed and are not Apple-notarized. Android keeps its existing signing identity.

The reported Windows long-session delay still needs a retest in the original environment.

Thanks @yuxino.
