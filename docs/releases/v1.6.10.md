## English

- Android now offers **System audio**, **Microphone**, and **Both**. System audio remains the default. Both inputs have independent capture, recognition and source-labeled captions; microphone-only does not request screen capture permission. Stop before changing the input.
- Android can save confirmed original and translated captions to private local sessions. **Save captions** is off by default and must be enabled before Start. Read saved sessions, export TXT or Markdown through the system document picker, or delete them explicitly. Turning saving off clears the current session's saved text. Stop keeps bounded confirmed captions readable until the next session; Android audio recording/export is still unavailable.
- OpenAI, Gemini and Azure OpenAI now offer simultaneous translation and **ASR + MT** on desktop and Android. New configurations default to simultaneous translation; switching modes preserves the separate text-translation configuration.
- Fixed Azure mode switching so a missing translation deployment can be filled without re-entering a saved key. Incomplete settings are no longer reported as an unreadable credential file. Failed xAI credential migration no longer commits a partial mode change.
- Fixed transient provider connection recovery, saved-key reuse for equivalent Android text-service URLs, and late settings responses that could select the wrong new profile or dismiss a reopened floating panel.

Thanks @wzg425065907-jpg for the Android feature request in #316.

Update through the app or download the package for your platform. Android uses the existing release package and signing identity. For portable Windows builds, quit Mimi before replacing the executable. macOS packages remain self-signed and are not Apple-notarized. Linux AppImages require host graphics libraries; on Ubuntu/Debian, install `libgles2` if startup reports it is missing.

Verification includes shared Rust/JNI regressions, signed macOS development UI and Android emulator capture/lifecycle and saved-session checks. Live provider accuracy/latency, physical-device microphone acoustics, full in-place updates and physical Windows/Linux/Android devices have not been validated for this release.

## 中文

- 安卓新增「**系统声音**」「**麦克风**」和「**双输入**」，默认仍为系统声音。双输入分别采集、识别并标明字幕来源；仅选麦克风不会请求屏幕采集授权。切换音源前须停止。
- 安卓支持将已确认的原文和译文保存为私有本地会话。「**保存字幕**」默认关闭，需在开始前开启。已保存会话可阅读、通过系统文件选择器导出 TXT 或 Markdown，或手动删除。关闭保存会清除当前会话已存文字。停止后仍可阅读有限的已确认字幕，开始新会话时清空；安卓仍不支持录音文件保存或导出。
- 桌面和安卓的 OpenAI、Gemini、Azure OpenAI 新增同声传译与「**ASR + MT**」两种模式。新建配置默认同声传译，切换模式会保留独立文字翻译配置。
- 修复 Azure 切换模式后补填翻译部署需要重输已存密钥的问题，缺少配置不再误报为凭据文件不可读取。xAI 凭据迁移失败时，不再留下部分完成的模式切换。
- 修复临时连接故障的自动恢复、安卓等价文字服务地址的密钥保留，以及较晚返回的设置请求可能选错新配置或关闭重新打开的浮动面板的问题。
