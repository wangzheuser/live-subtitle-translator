# Bundled provider icons

These local assets identify the corresponding services; no icon is fetched at
runtime. Names and marks remain the property of their respective owners and do
not imply endorsement. This catalog replaces the earlier third-party redraws
with first-party artwork, retrieved and visually checked on 2026-10-26.

| Local files | Official source and preparation |
| --- | --- |
| `deepseek.svg` | [DeepSeek Chat](https://chat.deepseek.com/) links to this [original blue SVG](https://fe-static.deepseek.com/chat/favicon.svg). Unmodified. |
| `qwen.png` | [Qwen](https://qwen.ai/) links to this [80 px favicon](https://img.alicdn.com/imgextra/i4/O1CN01OXv3EM1FN8t9W4P79_!!6000000000474-2-tps-80-80.png). Original pixels and blue; a white surface in dark settings preserves contrast. |
| `kimi.svg`, `kimi-dark.svg` | [Kimi Brand Book](https://www.kimi.ai/resources/kimi-brand) and [Logo Usage Terms](https://www.kimi.ai/policies/logo-usage-terms), downloadable Logo Assets archive: original `Logomark_Light.svg` (black tile / white K) and `Logomark_Dark.svg` (white tile / black K), both with the original blue dot. Used unchanged to identify the service; the file names describe the lettering, not Mimi's theme. The vendor use terms apply, not a third-party MIT license. |
| `siliconflow.svg`, `siliconflow-white.svg` | [SiliconFlow brand resources](https://www.siliconflow.cn/brand), [official SVG package](https://static02.siliconflow.cn/www/cn/res/20260615/SiliconFlow_LOGO.zip): standalone purple and white marks. Only the outer viewBox's empty padding is cropped; paths, fills and proportions are unchanged. |
| `bilibili.png` | [Bilibili's official GitHub organization](https://github.com/bilibili) links to this [200 px avatar](https://avatars.githubusercontent.com/u/12002442?s=200&v=4). Original pixels. Identifies Index-Translate's publisher, Bilibili, not an independently verified Index product symbol. The IndexTeam text avatar and detailed product illustration are unsuitable at 32 px; seasonal App Store artwork and the old WEB icon are excluded. |
| `baidu-qianfan.png` | [Qianfan's official product page](https://cloud.baidu.com/product-s/qianfan_home) links to the [Baidu AI Cloud ICO](https://bce.bdstatic.com/img/favicon.ico). Lossless extraction of its original 128 px frame. This identifies the cloud provider, not Baidu Translate or an independently verified Qianfan logo. |
| `ollama.svg` | [Ollama's official repository SVG](https://github.com/ollama/ollama/blob/d44c2581904a98430e348d89cc2af1529b1808a0/docs/ollama-logo.svg), original 17:25 shape and black fill. A white surface keeps it visible in dark settings without recoloring. The repository MIT license is included in [LICENSE.ollama](LICENSE.ollama). |
| `openrouter.svg`, `openrouter-white.svg` | [OpenRouter brand assets](https://openrouter.ai/brand): original transparent [Ink glyph](https://openrouter.ai/brand/logos/transparent/glyph/svg/glyph-ink.svg) and [Cloud glyph](https://openrouter.ai/brand/logos/transparent/glyph/svg/glyph-cloud.svg), retrieved 2026-10-25. |
| `lm-studio.svg`, `lm-studio-white.svg` | [LM Studio brand guidelines and use terms](https://lmstudio.ai/brand): original [color app icon](https://lmstudio.ai/assets/marketing/brand/download/logos/lm-studio-icon-color.svg) and [white outline app icon](https://lmstudio.ai/assets/marketing/brand/download/logos/lm-studio-icon-outline-white.svg), retrieved 2026-10-25. The gradient belongs to the original artwork. |

The other preset marks reuse the first-party OpenAI, Gemini, Tencent Cloud and
Volcano Engine assets documented in [provider-brand-assets.md](../../../docs/development/provider-brand-assets.md).
TokenHub and Volcano Ark use their cloud provider's mark because no independent
product glyph was verified; Hunyuan and the Doubao app are not interchangeable
with those services. Supplied dark variants are used as supplied. Static color
artwork is not inverted, recolored or replaced with an invented brand mark.
