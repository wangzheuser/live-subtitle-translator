## English

- Added xAI streaming speech recognition and independent Grok text translation. Choose another translation service for xAI recognition, or Grok for another supported recognizer.
- New xAI configurations default to streaming ASR and Grok text translation (`grok-4.3`, editable). Existing configurations keep Grok Voice; switch the speech mode to **Streaming speech recognition (ASR)** to try it.
- Recognition and translation use the usual separate settings, Save action and connection checks. Their keys are stored separately; the same existing xAI key can be used for both. Original-only captions skip translation.

Thanks @wzg425065907-jpg for the suggestion in #313.

Update through the app or download the package for your platform. For portable Windows builds, quit Mimi before replacing the executable. macOS packages remain self-signed and are not Apple-notarized. Linux AppImages require host graphics libraries; on Ubuntu/Debian, install `libgles2` if startup reports it is missing.

Live xAI latency and translation quality, full in-place updates, and physical Windows, Linux and Android devices have not been validated for this release.

## 中文

- 新增 xAI 流式语音识别与独立 Grok 文字翻译。xAI 识别可以搭配其他翻译服务，其他受支持的识别也可以选择 Grok。
- 新建 xAI 配置默认使用流式识别和 Grok 文字翻译（默认 `grok-4.3`，可编辑）。已有配置保留 Grok Voice，可将语音模式切换为「**流式语音识别（ASR）**」体验。
- 识别和翻译沿用原有的独立设置、保存与连接检查。密钥分别保存，可在两处使用同一个已有 xAI Key。仅显示原文时不请求翻译。

感谢 @wzg425065907-jpg 在 #313 提出建议。

可在应用内更新，或下载对应平台的安装包。Windows 便携版请先退出 Mimi，再替换程序。macOS 安装包仍采用自签名，未经 Apple 公证。Linux AppImage 需要系统图形库；Ubuntu/Debian 启动时若提示缺少 `libgles2`，请先安装它。
