## English

- Updated the desktop runtime and Linux AppImage graphics packaging to address blank windows on native Wayland and compatibility with newer Mesa graphics stacks.
- AppImages built with this change use the host graphics libraries. If startup reports `Couldn't open libGLESv2.so.2`, install `libgles2` on Ubuntu/Debian (`sudo apt install libgles2`).

Desktop and Android CI passed on the merged source. The contributor reported testing on CachyOS with Niri and Mesa; this does not establish compatibility with every Linux distribution or compositor. Physical Linux devices and full upgrade installation were not revalidated locally.

Thanks to @ryannyui for the toolchain upgrade and Linux AppImage fix ([#312](https://github.com/yuxino/Mimi/pull/312)).

## 中文

- 更新桌面运行时和 Linux AppImage 图形库打包方式，修复原生 Wayland 下的空白窗口及较新 Mesa 图形栈的兼容性问题。
- 包含此改动的 AppImage 使用系统图形库。如果启动提示 `Couldn't open libGLESv2.so.2`，请在 Ubuntu/Debian 安装 `libgles2`（`sudo apt install libgles2`）。

合并后的源码已通过桌面和 Android CI。贡献者报告在 CachyOS、Niri 和 Mesa 环境下测试通过；这不代表所有 Linux 发行版和合成器均已验证。本地未重新验证 Linux 实体设备及完整升级安装。

感谢 @ryannyui 贡献工具链升级和 Linux AppImage 修复（[#312](https://github.com/yuxino/Mimi/pull/312)）。
